# 現行管理表の確認と仕様への反映

確認日：2026年10月16日

参考スプレッドシート「請求一覧」（非公開資料・公開版ではリンク省略）を閲覧して、既存の管理項目と代表的な計算式を確認した。元シートには編集、コメント、設定変更を行っていない。

以下の「確認できた内容」はシート内の記録を示す。現在の契約条件・税務上の適用・全件の計算の正しさまで確定するものではない。会社名、案件名、個別の報酬・年収等は本メモへ転記せず、仕様に必要な構造を記録する。

## 1. 現行の構成

| シート | 確認できた内容 | 仕様での扱い |
|---|---|---|
| 26年度などの年別表 | 会社ごとに案件を並べ、1〜12月を横に配置。報酬、交通費等、小計、合計、源泉徴収、振込確認、年合計を保持 | 明細は一元管理し、会社×月の一覧を出力する |
| テンプレ | 年別表に近い構成と値引き率の設定 | 正本の実績表と区別し、初期値の参考にする |
| 案件金額表 | 同じ請求先の中に複数の案件・作業種別と単価。期間・距離・対面かオンラインかによる区分もある | 作業種別と単価条件をマスタに持つ |
| 時給計算表 | 時間×単価の計算、別欄に分単位の実績集計。月額・時間枠のメモもある | 時間・分入力に対応。月額・時間枠は現行利用を要確認 |
| 国民健康保険 | 国保、国民年金、住民税が同じシート内にある | 国保・年金は要求どおり対象。住民税は追加候補 |
| 光熱費 | 電気・水道・ガスの記録と集計 | 初期要件には追加せず、必要性を要確認 |
| 26年度_入力（サンプル） | 請求月、業務内容、件数、単価、自動報酬、交通費、小計、合計、源泉徴収、請求済、入金済、状態、請求先の補完 | 明細の入力項目と状態管理の参考。実運用の正本かは未確認 |
| 26年度_集計（サンプル） | 請求先×月と年間合計を、請求合計・源泉徴収で集計 | 集計画面の参考。年別実績と重複して取り込まない |

年別表には23年度から26年度のタブがある。タブ名だけから集計対象年や暦年・年度の意味を確定しない。移行対象は別途指定する。

## 2. 値引き率は期間ごとに保持する

「26年度」のA23・A33に1.3％、A24・A32に2％の値がある。例としてD23は元金額にA23を乗じ、BX23はA24を乗じる。月見出しと合わせると、この箇所は9月まで1.3％、10月以降2％を参照する構成になっている。別の請求先の10月欄にも2％を参照する式がある。

これは当該シートにある設定の確認であり、全取引先への適用や制度上の一律率を意味しない。新システムでは「値引きあり」だけで済ませず、率、対象額、適用開始・終了、会社・案件の例外を保持する。適用日の基準が作業日・締め日・請求日のどれかは確認する。

参照箇所：26年度!A23:A24、A32:A33、D21:D23、BP21:BP23、BX21:BX23、BX26:BX33。

## 3. 交通費と作業種別を明細に持つ

年別表には報酬と交通費等の別欄がある。請求合計には両方を組み込む式があり、報酬だけを管理すると現行の請求を再現できない。交通費等は、額・内容・税区分・値引き対象・源泉徴収対象を報酬と分けて確認する。

案件金額表では、同じ取引先の中に取材、執筆、編集などの単価区分がある。「会社→案件」だけでなく、その中の作業種別と単価を選べる案とする。期間や作業条件で単価が異なる場合も、請求確定時の条件を残す。

参照箇所：26年度!D1:I1、案件金額表!B11:D12、C23:E30。

## 4. 時間と分を換算し、契約メモを確認する

時給計算表には小数の時間を単価に掛ける欄と、分を足し合わせる欄がある。現行アプリは月次明細の小数時間×時給を使う。2026-11-02のユーザー指示でS25の日別稼働・時間／分入力は対象外としたため、参考表の分集計を追加開発の要件にしない。

「月額・料金」の欄には時間枠と月額料金のメモがある。これが現在も有効か、時間枠内は定額で超過分だけ時給なのか、単なる換算メモなのかは未確認。報酬タイプを増やす決定は保留する。

参照箇所：時給計算表!A2:F3、H2:L3。

## 5. 状態と日付を補う

サンプル入力には「請求済」「入金済」と状態欄がある。初期版もこのチェックを基本とし、当初明示されたMF消し込み済チェックを追加する。発行・送付・入金の日時や番号を新たに必須管理しない。

旧表に存在しない情報を推定で生成しない。請求書単位の合計・源泉徴収が代表行だけに入っている箇所もあり、各明細へ同額を複製しない。

参照箇所：26年度_入力（サンプル）!A1:N1、H4:L12。

## 6. 移行時に重複と集計行を除く

年別表は明細、小計、値引き、メモ、集計・グラフ用の行が同じシート内にある。すべてを売上明細として読み込まず、行の役割を判別する。

移行する場合は、正本シートと対象年を利用者が指定し、会社・月・請求単位を対応づける。年別表、サンプル入力、サンプル集計は同じ実績に由来する可能性があるため、自動で併合しない。取り込み後は会社別・月別の請求額と源泉徴収を旧表に照合する。

読み取り用データではGoogle Sheets固有の配列式などがExcel互換の代替表現になる箇所がある。これを元シートの計算エラーと判断せず、移行時は実際の表示値と元の業務ルールを照合する。今回は数式の再計算や全件監査は行っていない。

## 7. 現在の仕様への反映

2026年10月31日の指示により、現行表にない追加業務を初期範囲から外した。現在の範囲は[要求仕様書](要求仕様書.md)と[設計の決定記録](design-decisions.md)を参照。観察した項目・数式は10月16日の記録で、今回の再閲覧は行っていない。

住民税・光熱費は現行表にあるが、初期採用の合意はなく保留とする。月額・時間枠はメモの存在だけを確認しており、自動精算機能には広げない。値引きの具体的な計算条件と移行の正本・対象年は未決定。
